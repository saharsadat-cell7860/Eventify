# 🎟️ Eventify – Event Discovery & Booking Website

**Eventify** is a modern and responsive event discovery and booking website developed using HTML, CSS, and JavaScript. It allows users to explore events, view event details, book tickets, and manage their bookings through a simple and user-friendly interface.

---

## ✨ Features

- **Home Page:** Introduction to Eventify and featured events.
- **Explore Events:** Browse, search, filter, and sort available events.
- **Event Details:** View event descriptions, dates, locations, prices, and ticket availability.
- **Booking System:** Book tickets using a validated booking form.
- **My Tickets:** View, search, filter, and delete saved bookings.
- **Responsive Design:** Compatible with desktop, tablet, and mobile devices.
- **Local Storage:** Save booking information in the browser.
- **Interactive UI:** Dynamic content, buttons, forms, and navigation.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all folders and files are in their correct locations.
4. Open `index.html` in your browser.
5. For a better development experience, use the **Live Server** extension in VS Code.

---

## 💾 Booking System

Eventify uses the browser's **Local Storage** to save booking information.

Users can:
- Submit their booking details.
- View their saved bookings.
- Search for bookings.
- Filter bookings by status.
- Delete a booking.

**Note:** This is an educational project. It does not use a real payment gateway or a backend database. Booking data is stored locally in the user's browser.
